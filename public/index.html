1. Problem Formulation

EduLens formulates learning outcome prediction as a supervised 3-class classification task:

  • Input: Student utterances extracted from a learning conversation with an LLM.
  • Output: Predicted understanding level (understood, partial, confused).
  • Target Selection Rationale: Categorical understanding directly represents Bloom's cognitive progression without imposing arbitrary numerical conversions or fabricated quiz formulas.

2. Feature Engineering Pipeline

The model relies on a leakage-free Scikit-Learn ColumnTransformer:

  1. TF-IDF Vocabulary Vectorizer (100 features): Unigrams and bigrams capturing conceptual mastery vs. hesitation terms.
  2. Dense Conversational Signals (8 features): Scaled via StandardScaler:
    • Turn count & total words
    • Average words per turn
    • Question marks count
    • Confusion phrase markers
    • Clarification request markers
    • Understanding affirmation markers
    • Technical / code syntax indicators

✓ Leakage Prevention: Excludes sentiment and post-session quiz data.

5. Important Honest Limitations

  • ⚠️ Synthetic Dataset: 430 training sessions were synthesized with Claude using realistic pedagogical prompts rather than recorded classroom audio.
  • ⚠️ CS Domain Concentration: Focuses on university Computer Science subjects; generalization to non-STEM subjects has not been evaluated.
  • ⚠️ Independent Sessions: Current dataset represents independent sessions. Longitudinal growth curves require tracking user IDs across multi-week milestones.
