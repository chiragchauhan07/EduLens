About the Model & Methodology

Technical methodology underlying student understanding classification and linguistic confidence estimation.

Algorithm: Multinomial Logistic Regression
Test Accuracy: 95.89%

1. Understanding Classification Model

Supervised ML

A Multinomial Logistic Regression model trained with balanced class weights on 430 verified student learning sessions. Input is a 108-dimensional feature vector. The model outputs posterior probabilities across three target outcomes:

  • Understood: Comprehensive conceptual mastery and evidence (F1: 1.00).
  • Partially Understood: Emerging understanding with lingering gaps (F1: 0.92).
  • Confused: Persistent difficulty or misconceptions (F1: 0.90).

2. NLP & Feature Pipeline

108 Features

The dialogue is processed in a deterministic sequence:

JSON Dialogue → Student Utterance Extraction → Text Normalization → TF-IDF + Conversational Union → 108-dim Vector

Features comprise 100 lexical TF-IDF n-grams (domain vocabulary and causal markers like because, therefore) and 8 scaled conversational signals (turns, word volume, questions, confusion markers, affirmations, code syntax).

3. Expressed Confidence Estimation

Linguistic System

Confidence is evaluated using a rule-calibrated discourse analysis algorithm based on explicit conversational markers:

  • Boosters: Assertive statements (+9), independent explanations (+7), self-corrections (+5).
  • Dampeners: Uncertainty hedges (-8), hesitation fillers (-5), confirmation checks (-4), hint reliance (-9).

This is explicitly a linguistic marker estimate, not an ML classification model or psychological conviction test.

4. Limitations & Boundaries

Transparency
  • Dialogue Evidence Only: Evaluates only what the student expressed in the provided text conversation.
  • Vocabulary Domain: TF-IDF bank was trained primarily on Computer Science and STEM dialogue.
  • Language vs. Truth: Expressed confidence measures conversational tone. A student can sound confident while asserting an incorrect concept.
