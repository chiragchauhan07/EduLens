Data & Learning Ingestion

Ingest student study dialogues from external AI tutors (ChatGPT, Claude, Cursor) into the EduLens analytics pipeline.

Pre-fill Sample Learning Dialogue:

Accepts one student utterance per line, or JSON conversation object with messages/turns.

Ready to ingest.

code REST API Ingestion (`POST /api/ingest`)

Directly send JSON payloads from custom scripts or automated webhooks:

curl -X POST http://localhost:8000/api/ingest \
  -H "Content-Type: application/json" \
  -d '{
    "student_id": "student_001",
    "subject": "Algorithms",
    "topic": "Binary Search",
    "messages": [
      {"role": "user", "content": "How does binary search split?"},
      {"role": "assistant", "content": "It divides search space in half."},
      {"role": "user", "content": "Understood! Time complexity is O(log n)."}
    ]
  }'

hub MCP Connectivity (`/mcp`)

Streamable HTTP endpoint compatible with native ChatGPT and Claude MCP tools:

{
  "mcpServers": {
    "edulens": {
      "url": "http://localhost:8000/mcp",
      "headers": {
        "Authorization": "Bearer edulens_secret_token_123"
      }
    }
  }
}
