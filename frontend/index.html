108-Feature Cognitive NLP Architecture & Model Specifications

Technical methodology underlying student understanding classification and linguistic confidence estimation.

Algorithm: Multinomial Logistic Regression (Balanced)
Test Accuracy: 95.89%
1. 100 TF-IDF Features Vocabulary

Captures domain conceptual vocabulary, causal discourse connectors (because, therefore, which means), and subject-specific terminology with n-gram range (1, 2) and English stopword filtering.

2. 8 Conversational Signals Pedagogical

Extracts turn counts, total word counts, average utterance length, question frequency, confusion markers (lost, don't get), clarification requests, understanding affirmations (got it, makes sense), and code syntax indicators.

3. Confidence & Boundaries Transparent

Estimates expressed linguistic confidence using an assertion-to-hedge ratio and certainty tokens. Does not claim to measure internal psychological conviction. Designed as an educational evaluation aid.
